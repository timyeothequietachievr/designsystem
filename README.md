# The Quiet Achiever Design System

Public design system for The Quiet Achiever. Built with [Next.js](https://nextjs.org).

## Routes

- `/` — design system overview
- `/visual-library` — browsable component library
- `/preview/cXXX` — individual component previews
- `/component-catalog.json` — generated component catalog

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub, then import this repo on [Vercel](https://vercel.com/new). A custom domain such as `designsystem.thequietachievr.com` can be attached later.
